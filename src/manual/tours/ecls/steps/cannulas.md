- **Cannulation**: **VA** uses two cannulas, each with its own site. **VV (double lumen)** uses one cannula with two lumens, both in the right atrium.
- **Cannula type and size**: a smaller cannula costs more pressure at the same flow, and that cost rises steeply as flow goes up. **ΔP drainage** and **ΔP return** under *measured* show what each cannula costs.
- **Sites**: the compartments the cannulas sit in. In VV the return follows the drainage site.

The configuration decides what is supported:

- **VA ECMO** returns blood to an **artery** (e.g. the aortic arch). It supports both the heart and the lungs. The pump also works against the arterial pressure.
- **VV ECMO** returns blood to the right atrium. It supports the lungs only. There is no arterial pressure to overcome, but the narrow return lumen of a neonatal double-lumen cannula costs at least as much, so VV needs about the same pump speed as VA.
