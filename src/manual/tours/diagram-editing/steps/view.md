These settings apply to the whole diagram:

- **Grid** shows an alignment grid and snaps dragged compartments to it. The number sets the grid size.
- **scale** resizes all pictures, captions, lines and flow dots together.
- **O₂ lo / hi** set the oxygen-content range that runs from blue to red. Lower *hi* for low-haemoglobin circuits (e.g. adults) so arterial blood still looks red.
