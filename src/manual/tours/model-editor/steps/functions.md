Some models offer **functions**: actions rather than values. Examples:

- **Drugs**: start an infusion or give a bolus,
- **Fluids**: give a fluid bolus,
- **Heart**: trigger a premature ventricular contraction,
- **Ventilator**: switch it on or off, or trigger a manual breath.

Fill in the arguments (if any), then press the function's **▶** button to run it. Functions sit in the sections like any other field.
