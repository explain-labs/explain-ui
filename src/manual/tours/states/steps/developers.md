Model developers get a few extra controls in the bottom bar:

- **Save snapshot (file)** saves the state as a scenario file. Running locally, it appears straight away in the **local models** list. Elsewhere it is downloaded as a JSON file.
- The **star** next to the local models list loads that scenario at startup, before any cloud default.
- The **trash** icon deletes the selected scenario file, after a confirmation.

That's the end of the manual. Open **Help** whenever you want to revisit a chapter.
