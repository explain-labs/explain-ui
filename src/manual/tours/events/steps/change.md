For each change:

1. Pick the **model** and the **property** (the same fields as in the model editor).
2. *now:* shows the current value, and the target starts there. Set the value after the **→**.
3. **over**: the number of seconds the change ramps over (numbers only). 0 means instant.
4. **after**: a delay in seconds before this change starts.

Switches and lists change instantly, after their delay. **×** removes a change. Add as many changes as you need.
