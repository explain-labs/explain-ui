In the group editor:

- At the top: the **title**, **move up/down**, **delete**, and ✓ to close the editor. **shown** hides the group without deleting it; **collapsed by default** starts it folded.
- For each value: a **label**, then the **model** and **property** to read, or type a raw path such as `Monitor.minmax.abp_pres_max`. *now:* shows the current value, so you can check that the path works.
- **Add 2nd value (a/b)** turns a card into a pair.
- **unit**, **×** (display factor), **dp** (decimal places) and **/kg** (divide by patient weight) control how the value is shown.
- **Add parameter** adds a new value to the group.
