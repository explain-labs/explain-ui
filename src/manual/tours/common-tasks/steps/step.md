The **step** sets how big each click is:

- For most tasks it is a **percentage**. **+** multiplies by (1 + step) and **−** divides by the same amount, so **+** followed by **−** returns exactly to where you started.
- **Shunts** use **absolute** steps in their own unit (e.g. mm for the foramen ovale and VSD), so a closed shunt (0) can be opened.

Type another number to make bigger or smaller changes.
