Each series is a **model** plus one of its **parameters**: first pick the model (e.g. `LV`), then the parameter (e.g. `pres`). Both lists can be searched by typing.

- Series **A** is drawn in red, series **B** in blue.
- The **×** in a list clears that series.

Any numeric value of any model can be plotted, so you are not limited to the monitor values.
