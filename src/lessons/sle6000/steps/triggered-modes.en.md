The baby is now **breathing again**, and the ventilator is in **PTV** (patient-triggered ventilation). Every time the baby starts a breath, the ventilator detects the inspiratory flow (**Trig Sens**) and delivers a full PIP breath with it. The set rate is now only a back-up.

Look at the **measured rate**: it is higher than the set 40, because the baby triggers extra breaths.

Try the other modes via **Mode**:

- **SIMV:** only the set number of breaths is supported; the baby's other breaths go unsupported.
- **PSV:** each breath is supported, and the ventilator also ends the breath when the flow falls (**Term Sens**), so the baby also sets the inspiratory time.
