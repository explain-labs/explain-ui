Start de beademing met de knop hieronder. Die zet **CMV** aan (continue verplichte beademing): elke ademteug komt van de machine, drukgelimiteerd, met een vaste frequentie.

| | |
|---|---|
| PIP | 15 mbar |
| PEEP | 5 mbar |
| Frequentie | 40 /min |
| Ti | 0,35 s |
| O₂ | 21 % |

In deze les staat de eigen ademhaling van de baby uit, zodat elke ademteug die je ziet van de machine komt. (Bij de getriggerde modi komt die terug.)

Je kunt het ook zelf starten: **Mode → CMV → Confirm**.

> Kijk naar de **drukcurve**: een blokgolf tussen PEEP en PIP. Kijk nu naar de **CO₂-curve** op de monitor rechts: het capnogram. Waar in de ademteug stijgt die, en wat is de etCO₂?
